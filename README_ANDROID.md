# Cascade Android — порт-прототип

Цель проекта — перенести CASCADE (C++/Qt) в Android APK с подключением адаптера по Bluetooth SPP.

**Текущее состояние:** Android-прототип для проверки Bluetooth SPP и CI-сборки. Это ещё не полный CASCADE: эмуляторный движок C++/Qt и ROM не интегрированы в Android-приложение. Не используйте этот APK как замену оригинальному CASCADE.

## Сборка APK
Откройте вкладку **Actions** и запустите workflow **Android debug APK** (или сделайте push в `main`). APK публикуется как artifact `cascade-android-debug`.

## План порта
1. Проверить сборку Android-оболочки и SPP на Android 10 / K2401.
2. Перенести ядро C++ в Android NDK/JNI.
3. Реализовать Android UI и транспортный интерфейс, совместимый с ядром.
4. Добавить ROM-файлы, которые можно законно распространять, и проверить протокол на реальном оборудовании.

Исходный проект CASCADE — старый C++/Qt проект; обычная сборка Linux-проекта не создаёт Android APK.
